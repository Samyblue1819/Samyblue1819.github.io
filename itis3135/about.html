About

This course site is my work for ITIS3135 - Front-End Web Development at UNC Charlotte. It shows what I learn each module, starting with plain HTML and CSS and building up to JavaScript and full multi-page sites. Assignments, standards, and the schedule all come from my instructor's ITIS3135 teaching site.

Everything here is published in two places, my CLT webspace and my GitHub Pages site, so every link inside the site is relative and works from either copy. I write the code and check it with these tools:

  • VS Code - my code editor
  • Emmet - shortcuts in VS Code for writing HTML and CSS faster
  • Git and GitHub - version control and hosting through GitHub Pages
  • Browser developer tools - inspecting elements and testing on different screen sizes
  • Accumulus - the cloud validator that checks my HTML and accessibility
  • Vicunadator - the llama that checks each page against the course standards

By the end of the semester I will build these sites:

  • Personal home page - the root of my webspace that links to this course site

  • Whimsical product company - a fun business site for my mascot with its own look
  • Peer-management tool - an app for organizing and tracking peers
