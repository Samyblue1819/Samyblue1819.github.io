Website Evaluations

These evaluations rate two websites against the CRAP principles of design: Contrast, Repetition, Alignment and Proximity.

Stripe

  • Contrast: Strong. Big bold headlines, dark text on light backgrounds and brightly colored call-to-action buttons make it obvious what matters most and where to click.
  • Repetition: Strong. The same fonts, button styles, colors and card layouts repeat on every section and page, so the whole site feels like one brand.
  • Alignment: Strong. Everything sits on a clean grid with consistent left edges and spacing, so the page looks organized even with a lot of content.
  • Proximity: Strong. Related items like a feature's heading, description and link are grouped tightly, with plenty of white space between different sections.

Ling's Cars

  • Contrast: Poor. Almost everything is loud, bright and flashing, so nothing stands out; when everything is emphasized, nothing is.
  • Repetition: Poor. It mixes many fonts, colors, button styles and animated graphics with no consistent pattern, so the page never feels unified.
  • Alignment: Poor. Boxes, images and text blocks are scattered at different widths and positions with no clear grid to follow.
  • Proximity: Poor. Unrelated content is crammed together with little white space, so it is hard to tell which text, images and links belong to each other.
